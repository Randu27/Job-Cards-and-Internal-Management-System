# Job-Cards-and-Internal-Management-System
A comprehensive and modular Management System designed for a Graphic Print Hub. This application streamlines core business operations by integrating five specialized modules: Order Tracking, Financial Accounting, Resource Management, Customer Relationship Management (CRM), and Human Resources.

## How to Run
1. Clone this repository
2. Open `index.html` in your browser
3. Login to access dashboard
